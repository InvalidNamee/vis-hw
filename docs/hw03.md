## 已实现的用户流程

- 默认 643 条订单、6 条商品记录，固定种子生成的教学合成数据，有 3 条完全重复记录和 23 个缺失成本。
- 导入 CSV、TSV、对象数组 JSON，支持多文件、拖放、粘贴文本、UTF-8 / GB18030 / UTF-16 LE，以及逗号、分号、制表符分隔。
- 自动识别数值、文本、日期和布尔字段，保留 `001` 等带前导零的标识符；错误格式不静默丢行。
- 直方图与类别柱形可点击筛选；散点可框选。选择形成可编辑/删除的条件标签，和数据表、字段摘要联动。图表保留全量背景以供比较。
- 多条件 AND / OR 筛选，等值、文本包含、数值比较、缺失/非缺失。点击表头排序，缺失值固定放在末尾；每页 50 行。
- 字段摘要：唯一值、缺失数、最小/最大值、均值、中位数。缺失矩阵展示前 100 行，缺失统计使用全量。
- 缺失值均值/中位数/常数填充、删除指定字段缺失行、完全重复行去重。先预览行数、缺失数和样例，再应用。
- 分组、透视热力表、按月汇总；聚合包括 sum / mean / median / count / nunique / min / max / std，标准差采用样本标准差。
- 左关联、内关联和重复键展开预览。与 pandas 的空键匹配行为保持本版规定的一致；碰撞字段追加 `_right`，再次冲突时拒绝操作。
- 四则运算计算列，缺失传播，除零和非有限数值记为缺失，不执行任意表达式。
- 操作时间线、返回历史步骤、撤销/重做。历史步骤只读查看；从旧步骤继续或在撤销后应用操作时，保留原链为可恢复分支。每个源数据集保存独立的时间线。
- 导出当前选择对应的 CSV；导出、恢复 JSON 工作区备份，包含原始文件、操作及视图配置。
- 共用双语字典和计算逻辑。站点语言异步切换保留工作区、图表参数与选择；支持现有明暗主题和窄屏布局。

## 本地保存实现

`storage.ts` 使用 IndexedDB 数据库 `vis-hw03-v1`，两个对象存储：

- `assets`：原始文件 Blob，以 SHA-256 内容哈希为键，相同内容复用存储。
- `workspaces`：当前工作区的版本、数据集引用、各数据集操作、活动步骤和 UI 状态。

不将解析后的整张表写进每个历史版本。正常交互防抖 800ms 保存；事务完成后显示已保存。保存参数、资产引用和版本号在同一事务提交，失败保留上一份完整版本。原始内容哈希在内存中缓存，界面调整不必重复计算哈希。

每次写入检查预期版本号，另一个标签页更新后拒绝覆盖，提示备份当前页并刷新。第一版采用乐观版本检查，没有实现只读租约或标签页实时同步。

恢复时读取原始文件，重新解析并在 Worker 重放时间线。计算结果保留在内存，不持久保存统计缓存或检查点。页面关闭后无需重新选择已经保存的源文件。数据库异常时关闭自动保存，防止默认数据覆盖受损工作区。

存储管理支持开关自动保存、重试、本站配额占用估计、清除 HW03 数据及下载备份。清除后进入临时模式；不清除全站其他作业、主题和语言数据。容量不足不自动删除仍引用的源文件。

## 边界与未完成项

第一版限制：单次导入文件最大 10 MB；工作区最多 20 个数据集，原始文本总量最大 20 MB；数据处理最多 100,000 行、200 列及 200 万单元格；备份导入文件最大 50 MB；透视列最多 60 个类别。它们是实现保护阈值，并非实测性能保证。散点最多显示 1,500 个点，筛选和统计使用全量。

数值使用 JavaScript Number，不适合要求任意精度的金融计算。日期按 ISO 格式识别，月汇总使用输入日历年月，尚未做时区转换。CSV 当前要求首行为非空且唯一的表头。JSON 不支持嵌套对象。图表类别最多展示前 12 类；缺失矩阵最多展示前 30 列。

尚未实现：XLSX、URL 导入、导入前修改字段类型、字段重命名/删除、字符串转换、melt/concat/right/outer join、滚动平均、相关矩阵、IQR 标记、pandas 代码导出、多个命名工作区、IndexedDB 数据迁移、持久存储申请、持久计算缓存、LRU 和中间检查点、源数据来源跨浏览器自动同步。

浏览器存储依赖来源和浏览器配置，清除站点数据会删除工作区；JSON 备份负责跨浏览器迁移。本地处理不等同于离线可打开，第一版没有 Service Worker。
