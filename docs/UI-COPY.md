# UI 文案约定与检查记录

## 用词约定

- 作业列表和导航使用“作业”，文内层级使用“章 / 小节”。
- 已有内容标记“可查看”，没有内容标记“未添加”；不以“准备中”推断制作进度。
- 已有内容的卡片使用“查看作业”入口；没有内容的卡片不设入口，也不链接到占位页。首页主入口标出作业编号并带上章节名。
- 编号和名称同时出现时写成“HW01 · 网页空间布局”；只有编号、没有章节名的作业不再用“作业 02”复述编号，页面只在标题里显示一次。
- 统一入口名称：关于项目、博客、档案库、项目仓库。
- 教师规定的“讲解 / 关键代码 / 展示”保留不变。
- 演示控件区分浏览器视口与组件容器：“自适应宽度”“窄容器”。状态描述实际布局或明确成立条件，不保证任何设备上都会保持两列。
- 响应式条件写明断点，不用“手机 / 宽屏 / 窄屏”指代设备或宽度。视口规则写“视口窄于 560px 时”，容器规则写“预览宽度设为「窄容器」时”。具体像素值只写在说明实际条件的句子里，不进控件标签。
- 页面骨架的区域名称统一为“主内容区域”“侧栏区域”。
- 代码示例里的可见文字与对应演示保持一致，改演示文案时同步改代码示例。
- 静态示意图标注“非等比例”，不把代码示例尺寸标成图中实际尺寸。
- 方位说明优先使用区域名称，避免视口变窄重排后“左侧 / 右侧”失效。
- 外链保留新标签页提示；面向用户的中文入口不使用 ABOUT 等内部标识。
