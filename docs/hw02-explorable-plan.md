# HW02：让图形参与讲解

目标：学习 PAIR 的连续图形与可操作实验，增强“AI 如何成为生产力”的表达。保留双语、主题、来源、手机快照和六个详细专题。

1. 每幕一个持续存在的 SVG。滚动改变图形内部状态，使用稳定数据键过渡；不再交换多个固定主图。
2. 工作现场：知识、草稿、复核与交付在同一流程中展开；读者可以检查并修正一个明确标注的教学例子。
3. 产业能力：沿用同一关系网络，依次聚焦制造、医疗与科研；允许选择产业，看共用能力和不同验证条件。
4. 研究证据：时间、质量、临床与开发者研究按各自指标展开；用交互帮助辨认“速度”与“质量”，不混合研究结果。
5. 扩散与条件：100 格点阵展现比例，可切换年份与规模；资源流程、历史估计、未来预测和任务暴露明确区分。
6. 教学实验：同一流程的生产段缩短、复核段增长，参与率、速度和复核成本立即改变图形；展示盈亏临界点。
7. 内容围绕操作与因果展开。实测数据保持原来源与口径；新增演示必须注明教学性质，不能宣称产业实测收益。
8. 浏览器验证连续 SVG 身份、交互结果、键盘焦点、跨语言状态、减少动画、滚动返回、手机、超宽屏及全部专题回归。完成阶段及时 commit。
