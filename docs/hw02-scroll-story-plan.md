# HW02 滚动叙事结构方案

日期：2026-10-03。状态：已实施；多轮浏览器验收见 [实施与验收](hw02-scroll-story-acceptance.md)。

## 目标与阅读路径

主线回答“AI 怎样从技术能力变为生产力，以及收益为什么有条件”。将 `/hw02/` 改为完整滚动故事，现有六个子路由保留为深入探索入口。主故事用精选证据建立理解；详细页提供完整研究、行业选择和参数操作。双语保持同构。

默认阅读顺序：一个任务 → 能力进入流程 → 效率与质量证据 → 扩散差距 → 实现条件 → 读者实验。页面首先展示一个具体场景，再解释新质生产力，避免开头连续堆概念与数字。

## 主故事的六幕

| 幕 / 问题 | 滚动步骤与视觉变化 | 复用资源 | 深入入口 |
|---|---|---|---|
| 01 一个工作现场 | 客服遇到问题 → 查找知识 → AI提供建议 → 人复核后交付。固定流程图分步高亮，结尾展示该研究约15%的总体结果及样本限定。 | `collaboration`图解、`support`记录、QJE来源 | 人机协作 |
| 02 能力怎样进入产业 | 先展示识别/预测/生成能力，再连接制造/医疗/农业/科研/服务；精选制造、医疗、科研三个场景讲解。滚动突出网络的关联边，旁边出现一个短案例说明。 | 产业网络、cases/capabilities、医疗配对图、AlphaFold机制 | 产业图谱 |
| 03 生产力要怎样验证 | 写作耗时与质量分两步；医疗质量另作单独证据；开发者对照收尾说明收益依赖任务。每步只出现当前研究的指标、样本和局限，独立刻度切换。 | effects、medical、developers及原来源 | 人机协作/医疗案例 |
| 04 技术在扩散，机会却不均衡 | 采用率2023→2025逐点揭示；切换到欧盟小中大型企业2025年差距。两组图分别呈现，标题切换时同步单位/总体。投资及中国背景作为短注释与深入入口。 | adoption、enterprise、investment、中国背景记录 | 发展脉络 |
| 05 收益需要什么条件 | 能源/算力/数据图解 → 2025估计与2030用电预测 → 人才/流程与职业任务暴露。图示从资源网络切到能源图，再到暴露图；每次只解释一个问题。 | infrastructure、energy、exposure、ILO/IEA来源 | 转型与边界 |
| 06 把假设交给读者 | 展示串行任务基准 → 加速生产阶段 → 加入复核成本，最后给出自主操作实验入口。三步预演使用教学假设，最后点击“亲手调节”进入实验室。 | calculate/defaults/presets、lab流程与sensitivity图 | 生产力实验室 |

主故事约15–18个短步骤，每步一个判断、约60–100字中文，搭配一张主图或一个明确状态。避免按每个指标增加一整屏；原图数据表、来源脚注继续可查。预计桌面阅读约5–8分钟，实际长度以首版试读调整。

## 版式

- 首屏：现有科技主视觉，标题、一句问题和“开始探索”锚点。取消首屏重复概念卡和多组数字摘要；将中国背景放到第四幕短注释。
- 幕间：全宽章节标题/短结论，用现有两张海报局部裁切形成分组。不在每幕重复双指标封面和独立卡片标题。
- 桌面：每幕一侧约35–40%的文字步骤，另一侧约60–65%的固定图。整个幕是sticky边界；图保持到最后一步后自然离开。卡片、幕标题与页脚共用左右边线。
- 窄屏/矮屏：取消sticky，按“步骤标题 → 短说明 → 图/静态快照”正常阅读；尽量一个幕一张可更新图，长步骤配就近状态摘要。若状态更新时图已不在视口，不依赖更新后的图才能理解正文。必要时对关键结果采用每步紧凑快照，控制重复高度。
- 高度不足以同时容纳导航、图和脚注时自动使用普通流；不压缩SVG文字来强塞sticky。
- 主故事侧栏显示六幕锚点与当前阅读位置，底部保留“深入探索”入口；详细页侧栏继续按路由导航。手机章导航折叠，进度不额外占一整层顶部栏。
- 结尾：三句对应效率、质量、创新的结论，加产业探索/实验室/来源三个入口。全页只有一个页脚。

## 六个深入页面的角色

| 路由 | 新角色 | 内容处理 |
|---|---|---|
| trends | 数据探索 | 保留采用、投资、企业规模等完整图与表；减少重复的落地路径长解释 |
| industries | 自由选择产业 | 保留手动产业选择和网络/矩阵，当前案例与证据联动；不让页面滚动改动用户选择 |
| work | 研究对照 | 保留客服/写作切换与开发者两个独立研究，补足样本和限制；机制图成为简短导读 |
| lab | 自主实验 | 四参数、预设、播放、分享与敏感性曲线保留；滚动不自动改参数 |

主故事可以再次使用子页的数据和绘图，但不复制整页内容；主故事里的摘要跳转到对应完整证据/带合法参数的产业案例。研究期、预测性质和单位在两种展示中必须一致。

## 交互规则

1. 主故事先由步骤决定图的状态，不同时出现另一套产业/指标筛选按钮。探索页由用户控件决定状态。两种模式使用同一绘图接口，避免状态争抢。
2. 下滚进入步骤、上滚返回步骤，状态可逆；快速跳幕或打开锚点直接显示当前状态，不依赖前一段动画运行完。
3. 点击侧栏和“开始探索”使用普通锚点。当前章节进度可读取，但不随每次滚动改写全站查询参数或创建浏览器历史记录。
4. 图首次接近视口才初始化；数值、说明、来源及表格预先存在。隐藏深度模块不预先启动计时器。
5. 入场转场约250–450ms，数值揭示和路径高亮服务解释。滚轮不被截获，不自动滚动，不强制整屏吸附，不自动播放实验动画。
6. 减少动态效果时状态直接切换；关闭JS仍能读到全部论点、来源及关键数据。图变换不移动焦点，不逐次播报大段aria-live文字。

## 组件与实现组织

### 可复用

- `dataset.json`/`content.ts`：30条指标、21个来源；继续从同一数据出口生成图表、摘要、表格和下载。
- `graphs.ts`：落地路径、客服知识协作、基础设施矢量场景。
- `evidence-charts.ts`：企业规模、机器人、医疗、开发者、暴露图。
- `science-graphs.ts`：科研/气象机制。
- `model.mjs`：教学模型和预设。主故事预演与实验室共享计算，不使用研究百分比填充模拟参数。
- `Source`、数据披露、现有图片、主题变量、双语与base路径处理。

### 新增 / 调整

- `StoryChapter.astro`：标题、固定图区域、步骤区域、简短来源。
- `StoryStep.astro`与双语故事配置：稳定幕/步骤ID、主问题、目标绘图状态、来源、深入链接。
- `story.ts`：观察当前步骤与章节，处理锚点直达、减少动态效果和生命周期清理。初版用IntersectionObserver配合稳定的当前步骤选择；不引入连续逐像素动画库。
- 从`charts.ts`逐步提取现有复杂绘图；让图接受明确状态，如`mode: story|explore`、`activeIndustry`、`activeOutcome`、`revealedYears`，避免主故事通过修改全局URL驱动子页控件。
- `PosterHeading`拆为可复用装饰/标题，主故事幕间用精简变体。
- 图ID、marker ID和控件命名按实例唯一；复用同一图多次时不会互相选择DOM、覆盖aria关联或来源折叠。

数据不需要为此次结构改造新增一批指标。缺乏可靠证据的行业继续使用机制解释，不补虚构收益。

## 实施顺序与验收

1. **故事骨架**：确定六幕双语文案、稳定锚点、桌面/手机布局，先用现有图静态填充。保留原详细路由。
2. **核心示范幕**：先做第一幕客服流程与第三幕研究证据的滚动切换，验证读者能看懂、移动端能读、图不跳高，再推广。
3. **其余章节**：复用产业、采用、资源/暴露和实验模型；收紧重复文字，整理深入链接。
4. **生命周期和性能**：接近视口初始化、实例隔离、主题/resize、语言切换后的观察器清理及重建、无JS与减少动态效果。
5. **完整验收**：双语、明暗、320/390/768/1024/1440/1920px及矮窗口；正常上下滚、快速滚动、跳章、刷新锚点、键盘导航、主题/语言切换、数据表/下载与base部署。原产业手动选择和实验分享无回归。

完成标准：仅看主故事就能解释AI影响效率、质量与创新的路径及条件；每幕一句主论点、有证据或明确机制说明；普通滚动顺畅；手机与减少动态效果用户获得同样的事实内容；没有重复初始化/事件/图形残留。
