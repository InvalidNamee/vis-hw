## 统一规范建议

- 间距阶梯：4、8、12、16、24、32、48。普通卡片桌面20–24px、移动16px；数据密集卡片允许12–16px。
- 普通页面共享容器，外边距手机16px、平板24px、桌面32px；最终max-width与导航一并校准。文章阅读列限制行长；HW02保留贴左侧栏和铺满余下空间的工作区。
- 普通按钮高36px，重要操作40px，移动触控区域至少44px；纯图标按钮宽高相等。图标通常16px，独立图标18–20px；图文gap8px，内联外链gap4px。
- 图文按钮inline-flex、垂直居中，svg不收缩；多行外链图标贴近链接文字，避免在长来源标题中变成远端装饰。
- 同组按钮同高；选中、悬停、禁用、键盘焦点分别定义。保留Lucide，GitHub品牌图标仍使用现有品牌资源。
- 卡片圆角建议普通10px、海报12px、控件6px；统一边框与背景token。首页可保留浅底分组、HW02保留海报与机制图主题色。
- 视觉密度通过合理并列、减少重复说明与空行获得，不继续压小字体。

## 实施顺序

1. **公共框架**：统一容器/页脚边距、空目录布局、短页面落底和三种页头节奏。
2. **按钮图标**：共享尺寸与状态规范，迁移导航、主题、语言、下载、侧栏、分页及HW01演示控件；手机辅助导航合理重排。
3. **HW02局部**：来源工具栏、实验室左右列、标题/说明字号、卡片内边距和移动正文边线。
4. **样式整理**：归并重复规则，避免继续堆叠高优先级覆盖；不调整D3数据与交互行为。
5. **验收**：首页/HW01/HW02七页/关于/占位模板，中英文、明暗主题，320/390/768/1024/1440/1920px；检查按钮基线、触控区、长标题、展开数据表、侧栏滚动、单一页脚及所有主要左右边线。再运行check/build/现有测试。

完成标准：同种组件同种规格；一屏中页头、工具栏、内容、页脚具有清晰对齐关系；不同页面类型保留必要的内容结构差异。

## 实施与验收

- 公共容器与导航统一最大宽度和响应式边距（32/24/16px）；页脚跟随容器，短页自然落底。
- 无目录文章使用800px居中阅读列；有目录文章保留目录。首页、文章、专题各自保持明确的页头节奏。
- 语言、主题、图标按钮使用共享控件高度；手机辅助导航分两行，目标点击区至少44px。HW01标签及演示按钮、HW02操作按钮、下载与翻页同步规格。
- HW02手机正文边距16px；说明13px、来源12px；来源工具栏窄容器分行，搜索占满宽度；实验室右侧改为独立纵向栈。
- 外链文字与图标保持内联，并将图标前空格与图标绑定，降低图标孤立换行；归并导航和主按钮重复声明。
- `npm run check` 零诊断；构建28页；15项现有测试通过。
- 浏览器：11种页面/模板 × 双语 × 6种宽度 × 明暗主题 = 264组，无页面异常、横向溢出、重复页脚；目标控件的手机点击区及普通页脚边线检查通过。
- 交互回归：语言切换保留预设、主题开关、手机侧栏开关、滚动到底部侧栏位置、来源筛选、手机搜索宽度、短页页脚落底通过。
