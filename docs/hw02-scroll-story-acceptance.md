# HW02 滚动故事实施与验收

> 本文记录连续图形升级前的阶段验收。后续已提交，并改为每幕一个持续存在的 SVG、可操作情景及参数传递；当前实现和测试结果以 [Explorable 验收](hw02-explorable-acceptance.md) 为准。

日期：2026-10-03。实施、多轮修正及浏览器验收跨度超过一小时。保留工作区原有修改；本次未提交或部署。

## 已实施的结构

首页为六幕、18 步的双语滚动故事：客服现场 → 产业能力 → 研究证据 → 扩散差距 → 资源与任务边界 → 教学实验。每步一个论点、图形状态、限制说明和深入入口。中文正文约 75–104 字。

保留六个详细路由：发展脉络、产业图谱、人机协作、实验室、转型与边界、来源与方法。主故事滚动状态独立于详细页的 URL 筛选和实验参数。

## 方案逐项对应

| 要求 | 实现与证据 |
|---|---|
| 六幕完整主线 | `story-content.ts`，六个稳定幕 ID、18 个步骤 ID；两种语言发布相同结构 |
| 科技首屏、精简幕间、三个结论与深入入口 | `Story.astro`、`StoryChapter.astro`；复用原有配图，首页不再有重复概念卡、页码和章节翻页栏 |
| 宽屏固定图、窄屏与矮窗口普通阅读 | `story.css`、`story.ts`；文字/图列 36/64；宽度不足 1100 或高度不足 740 时普通流，图卡实际超高也切回快照 |
| 图卡不跳高、图谱不抢滚轮 | 每幕测量最大场景高度；固定关系布局，未加入缩放、拖拽、滚轮拦截或滚动吸附 |
| 手机就近快照 | 每步正文后有对应场景；增强前预留与绘图接口一致的高度，避免延迟绘图使跳章偏移 |
| 章节侧栏与进度 | 六幕普通锚点与当前章节提示，原详细路由为深入入口；手机选章后关闭抽屉 |
| 现有数据、图解与模型复用 | 30 条指标、21 个来源继续由同一 JSON/CSV 出口提供；抽取量化图与产业绘图；复用机制图、证据图、科研图和 `calculate` |
| 证据、机制与教学假设区分 | 图卡类型、样本、期间、限制、来源、数据表保留；不把采用率当生产率，不把未来预测当观测，不混合不同研究指标 |
| 上下滚动可逆、快速跳章 | 当前步骤由位置直接确定；快速跨六个步骤再返回，状态均匹配；不依赖动画顺序 |
| 惰性初始化与生命周期 | 接近视口才绘制；监听器通过 AbortController 清理，观察器和 D3 转场断开时停止；十次语言切换后监听器仍为 18 个、没有重复 ID |
| 双语切换保留阅读位置 | 以稳定步骤 ID 和相对位置恢复；实际鼠标切换后的偏差小于 1px |
| 无 JS、减少动态效果 | 无 JS 的中英文页均保留 18 个可读快照与 20 个来源链接；减少动态效果时直接显示最终状态 |
| 不抢焦点、不污染 URL | 跨章节滚动后焦点、URL 与历史长度保持不变；打开过高数据表切到快照时保留展开状态和对应摘要焦点 |
| 独立实验室 | 四参数、预设、播放/暂停/继续/重播、默认重置、分享和敏感性曲线保留；故事预演不写入详细页参数 |
| 方法与署名 | 来源页补充滚动实现说明；素材署名、JSON/CSV 下载和原研究说明保留 |

## 验收证据

- `npm run check`：68 个文件，0 errors / 0 warnings / 0 hints。
- `npm run build`：28 个页面构建成功。
- `node --test tests/*.test.mjs`：17 项通过；覆盖十四个 HW02 路由、来源、下载一致性、稳定锚点、唯一实例、无 JS 事实与模型边界。
- 主故事浏览器矩阵：320 / 390 / 768 / 1024 / 1440 / 1920px × 中英文 × 明暗，共 24 个组合、432 个场景。检查实际绘制、步骤对应、SVG 文字边界、横向溢出、重复 ID 和幕内图卡高度。
- 固定图边界复测：1440 / 1920px × 中英文 × 明暗，144 个步骤检查，图卡标题到来源完整位于导航下方与视口以内；末步骤延长后再自然释放图卡。
- 详细页回归：390 / 1440px × 中英文 × 明暗 × 六个详细页，共 48 个组合，无页面错误、横向溢出或缺失图形。
- 产业键盘操作：Vision 节点按 Enter 后能力面板显示且焦点保留；关联产业及矩阵切换同步更新 URL。
- 模型：高复核情景为 -7.3%；重置后为 14.5%，默认重置按钮禁用；播放暂停后为 Resume，完成后为 Replay。
- 分享：模拟剪贴板 `writeText`，确认提交的链接与当前 URL 一致，包含四个实验参数和播放速度；系统剪贴板未改动。
- 来源搜索：无匹配时 0 条并有提示，清空后恢复 21 条。
- 子路径构建：`npm run build -- --base /vis-hw/ --outDir ./output/playwright/base-build` 成功；本地挂载后内部链接、七张延迟图片、CSV/JSON 均可读取。
- 刷新直达：六种宽度 × 中英文 × 三个步骤/章节锚点，共 36 次刷新，目标位置均在导航下方约 24px；初始校正遇到用户滚轮、触摸或按键立即取消。
- 额外边界：1440×600 窗口普通流；1440×800 展开医疗数据表后快照仍打开、可见且焦点保持；原生手机跳章单独复测。

## 沉浸式展示追加迭代

2026-10-03：引入 GSAP / ScrollTrigger，仍由 D3 绘图和原故事控制器选择当前场景。

- 封面铺满正文区域，增加轨道装饰、背景纵深和随滚动移动的图层。
- 章节使用大幅配图、缓慢视差、主题色环境背景、轻微文字入场和顶部阅读进度条。
- 首页侧栏默认收窄，可展开；首页与详细页分别保存侧栏偏好。深入入口恢复各专题自己的图标。
- 固定图卡最大宽度 860px，文字、图形标题和来源对齐；窄屏继续使用就近快照。
- 动画只变换装饰和文字，不固定或变换章节祖先，不接管滚轮；CSS 原生平滑滚动在故事页关闭，避免与 ScrollTrigger 测量发生冲突。
- 动画采用 GSAP context 管理，在组件断开或减少动画设置改变时回收；保留当前滚动位置。原 SSR 事实、来源及无 JS 阅读结构继续保留。

追加验收：390、768、1440、1920px × 中英文 × 明暗主题，共 16 组合 / 288 步，无横向溢出、缺图、固定卡越界或页面脚本错误。正常模式确认进度条和背景变换实际运行；减少动画模式清除装饰变换并隐藏动画进度条。最新构建完整刷新后，科学发现锚点位于页头下约 24px；开关减少动画前后 scrollY 均为 4779，锚点位置均为 89.47px。实际鼠标切换语言的阅读位置偏差小于 1px。

`npm run check`：69 文件，0 errors / warnings / hints。`npm run build`：28 页面。`node --test tests/*.test.mjs`：17 项通过。
