# HW02 独立展示与同步滚动

日期：2026-10-03。

## 问题与改变

旧版文字在普通文档流里滚动，右侧图形仅跨步骤时切状态。即使 SVG 保持不变，文字与图形仍有不同的时间节奏。

新版在宽度至少 1100px、高度至少 740px 且图形能容纳时，将文字与图形放入同一 sticky 舞台。原步骤仅提供原生滚动距离，不拦截滚轮，不强制吸附。每一步按其实际位置计算 0–1 的进度：文字与图形同步出现、停留和淡出；流程中的信息点移动、网络连接逐步展开。数值与研究尺度不因动画改变。缩小窗口、卡片过高、无 JavaScript 时使用普通图文阅读。

首页独立于课程展示框架：单层精简导航、六幕入口、来源、语言和主题；删除首页侧栏。专题继续使用原有探索布局。共享 BaseLayout 的 exhibition 变体只在独立首页启用，其他课程页面保持各自导航。

每场景首先显示一条短说明；完整正文可展开“情境与限制”。数据表、来源和教学标识继续保留，投入、采用率、资源需求与研究效果不混用。

## 主要文件

- `exhibition.css`：独立页面、精简导航与同幕舞台。
- `story.ts`：同步滚动、实时图文状态、焦点迁移和窄屏回退。
- `story-graphics.ts`：滚动表现进度，不改动实测数据。
- `story-beats.ts`：十八条中英文场景短说明。
- `BaseLayout.astro` / `Hw02Layout.astro`：首页导航隔离；详细页保持探索入口。
