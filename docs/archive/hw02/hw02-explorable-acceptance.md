# HW02 连续图形与读者实验验收

日期：2026-10-03。参照 Google PAIR AI Explorables 的连续场景与读者实验组织方式，复用 D3、现有数据与专题。实施和验收超过一小时。

参考：[官方源码](https://github.com/PAIR-code/ai-explorables)、[校准示例滚动控制器](https://pair.withgoogle.com/explorables/uncertainty-calibration/draw_slides.js)。采用“滚动选择场景 + 同一图形过渡 + 读者调整变量”的方法；本项目保留 Astro 静态构建与 D3，并使用 GSAP 管理装饰动画。

## 方案落实

| 目标 | 实现 |
|---|---|
| 连续画布 | 六幕各一个主 SVG，按稳定键更新内部节点；18 个手机快照，总计 24 个场景实例。删除已无调用的旧场景渲染器。 |
| 工作现场 | 同一知识→草稿→复核→交付流程；补齐换新建议的购买、保修与故障条件。教学示例与客服研究平均效果分开标注。 |
| 产业能力 | 同一九节点网络，读者选择制造、医疗或科研；对应的三段任务路径、说明与证据同时更新。固定布局，不占用滚轮。 |
| 研究证据 | 时间与质量各有基线和指标，允许只看时间或加入质量；临床和开发者研究保留独立尺度与研究范围。 |
| 扩散与条件 | 100 格比例点阵，年份与企业规模可切换。宽屏 20 列、手机 10 列，保留小数比例。资源依赖、2025 估计/2030 预测、收入群体任务暴露各有可操作选择。 |
| 教学实验 | 生产段与复核段随参与率、加速和复核参数变化；固定工时轴、净收益和盈亏临界点帮助比较。链接携带当前实验参数。 |
| 内容与口径 | 30 条指标、21 个来源保持统一数据出口。采用率不视作生产率；任务暴露不视作失业率；资源依赖不生成虚构收益。 |
| 状态与可访问性 | HTML 控件有标签与选中状态；状态文字只在变化时播报。语言切换保留参数，减少动画时停止过渡。尺寸变化后恢复对应控件焦点；用户滚轮、触摸或键盘输入取消延迟恢复。 |

## 验收

- `npm run check`：71 个文件，零错误、警告及提示。
- `npm run build`：28 个页面构建成功。
- `node --test tests/*.test.mjs`：18 项通过。临界点回归覆盖 21 个参与率 × 15 个加速值 × 3 个任务数量，共 945 个情景，临界点收益为零且两侧符号正确。
- 浏览器实际鼠标操作：资源关闭、预测切换、暴露群体、科研产业、2023 年采用率、负收益及小数临界点均更新图形与说明。
- 实验复核 20 分钟显示 −7.3%；80% 参与、3 倍加速的临界点为 16 分钟，收益 0.0%，链接参数同步。85% / 2.5 倍时临界点为 15.3 分钟。
- 键盘可调滑块；中文转英文后参数保留，阅读位置偏差小于 1px。减少动画开关不改变当时阅读位置。
- 桌面与手机连续来回切换四次：复核滑块均保留 12.5 的值、焦点与 accelerated-production 步骤，控件位于可见区域。
- 320 / 390 / 768 / 1024 / 1440 / 1920px × 中英文 × 明暗主题，共 24 组、432 个场景通过。实际主题底色分别为 #fff / #24292e；无缺图、错配、溢出或固定主 SVG 替换。
- 中英文六个专题共 12 页在 390px 下返回 200，无横向溢出；无脚本模式两种语言均保留 18 步和事实说明。390px / 1440px 刷新实验步骤锚点位于页头以下约 24px。
- 展开客服研究数据表后，摘要保留焦点与展开状态；卡片能放入 900px 高视口时继续固定显示。
- 最终截图：`output/playwright/explorable-final-mosaic.png`、`output/playwright/explorable-final-mobile-science.png`。
