# HW02：架构与验收

## 当前展示

中英文各七页：六幕、18 步的沉浸式首页，以及发展脉络、产业图谱、人机协作、实验室、转型与边界、数据与方法六个专题。全站导航与页脚使用共享组件。

宽屏在 ≥1100px、≥740px 且图文实际放得下时启用固定舞台；其他窗口使用连续正文与就近图形。展开内容超高也会退出固定展示。使用原生滚动，产业图谱不截获滚轮。

## 文件职责

```text
src/homework/hw02/
  Page.astro           路由分发，不承载专题正文
  Hw02Layout.astro     全站布局接口、专题侧栏、统一页脚
  content.ts / meta.ts 数据访问和专题信息
  model.mjs            唯一的教学计算模型
  shell.ts             专题侧栏交互
  pages/               六个独立专题正文
  story/               内容、状态、控制器、绘图、交互、封面动效
  visualizations/      专题图表控制器及分类绘图
  components/          图表、来源、选择器、故事章节等容器
  styles/
    theme.css          专题颜色、留白、控件变量
    layout.css         专题框架、网格、导航及页脚
    components.css     配图标题、卡片、工具栏与公共控件
    story.css          连续图文、固定舞台、快照与故事控件
```

步骤的双语短文 `summary` 与完整说明 `body` 同处 `story/content.ts`。统计数据唯一来源为 `public/data/hw02/dataset.json`；CSV 由 `scripts/hw02-data.mjs` 生成。仍为 30 条指标、21 个来源。

## 视觉与交互约定

- 正文最大宽度 1440px，故事舞台最大宽度 1600px；专题侧栏贴左，正文、标题和页脚沿相同边界对齐。
- 留白：桌面 48px、平板 24px、手机 16px；卡片内边距桌面 24px、手机 16px，圆角 12px。
- 控件点击区域至少 44px，图标与文字居中。较多选项在卡片容器不足 560px 时切换为原生下拉，仅展示一种控件。产业工具栏在卡片宽度大于 640px 时并排，否则分行。
- 图文进度由故事控制器管理；GSAP 只处理封面图片。减少动态效果关闭图文转场和封面动效。
- 路由、步骤锚点、查询参数、语言切换和键盘操作沿用现有协议。机制图、教学模型、统计证据各自标明性质与限制。
- 样式限定在 `.hw-shell` 内；仅页面滚动行为使用 `html:has(.hw-shell[data-story])`。不覆盖其他作业的全局组件。
