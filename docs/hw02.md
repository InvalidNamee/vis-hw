# HW02：沉浸式滚动故事

更新：2026-10-04。

## 展示与内容

主题为“人工智能怎样成为新质生产力”。中英文各有两个正式页面：

- `/hw02/`：封面、六章／21 个滚动步骤、章末完整探索、结尾。
- `/hw02/sources/`：30 条指标、21 个来源、检索筛选、口径、方法、下载与素材署名。

英文地址加 `/en/`。沿用全局 nav、主题和语言切换；HW02 内部使用 44px 章节条、目录、当前位置和阅读进度，移除大侧栏。正文最大宽度为 1440px。全页只有一个全站页脚。

| 章节 | 主线内容 | 章末探索锚点与完整材料 |
| --- | --- | --- |
| `workplace` | 检索、AI 辅助、人的复核与交付 | `workplace-explore`：效率、质量、创新 |
| `capabilities` | 制造、医疗、农业、科研、服务五个场景 | `applications`：全部案例、网络／矩阵、机器人、医疗、气象与科学发现 |
| `evidence` | 客服效率、写作耗时、写作质量、开发者差异 | `benefits`：原指标切换、研究对照与条件 |
| `diffusion` | 采用率、规模差距、投入背景 | `adoption`：年份选择、私人投资、企业规模、中国背景 |
| `conditions` | 物理资源、用电、任务暴露 | `boundaries`：能源口径、就业暴露、基础条件 |
| `experiment` | 基准流程、生产加速、额外复核 | `parameters`：四参数、三预设、流程播放、敏感性、分享 |

保留原有 14 类图表、五个产业案例及独有解释；完整图表在本页原生 `details` 中展开。实验区默认展开。主线预计阅读 8–12 分钟，是内容设计目标，并非用户试读测量。统计数据与模型保持原有口径，机制图和实验明确标注教学性质。

## 文件职责

- `navigation.ts`：两个正式入口与五个旧专题入口；`compatibility.ts`：旧步骤锚点。
- `Page.astro`、`Hw02Layout.astro`：路由分发、公共框架适配、轻量目录。
- `story/content.ts`：六章、步骤 ID、双语文案、图形目标、来源与探索入口。
- `story/Story.astro`：一次生成可读正文、步骤、章末探索和结尾。
- `story/controller.ts`：接近视口初始化、滚动位置、响应式、观察器与时间线清理。
- `story/narration.ts`：桌面固定文字舞台、段落进出、交互可见性与原正文位置恢复。
- `story/graphics.ts`：场景绘制接口 `mountScene`，返回 `seek / resize / destroy`；复用分类绘图，流程与模型状态直接按进度计算。
- `story/navigation.ts`：目录、进度、深层锚点、展开目标与焦点。
- `interactions/lazy-charts.ts`：按需导入探索图表运行时；`visualizations/charts.ts`：各探索实例独立初始化和生命周期。
- `interactions/`：实验、产业、来源、URL 状态、手动演示和控件过渡。
- `pages/Industries.astro`、`pages/Lab.astro`：嵌入式完整探索内容；其他正文片段位于 `components/sections/`。
- `data.ts`、`model.mjs`：单一数据入口与教学模型；`public/data/hw02/dataset.json` 生成下载 CSV。
- `styles/story.css`：封面、舞台、步骤、手机与回退；其他样式分别负责主题、通用布局、控件和探索内容。

删除停用的概览页面、侧栏控制器和旧入场脚本；不恢复旧版整套滚动控制架构。共享布局、全局样式、语言切换、其他作业与依赖清单未修改。

## 滚动、动画与加载

CSS sticky 将舞台限制在每章内。GSAP ScrollTrigger 读取滚动位置，约 0.35 秒平滑追随，D3 负责图形和尺度。流程段宽、复核成本与总工时按当前步骤进度直接计算，支持向上倒回和跳到任意步骤。同类流程及产业网络保留 SVG；不同指标图层以约 280ms 交叉淡化衔接，标题、单位和来源同步切换。

桌面正文也固定在章内舞台。工作流程与条件章保持左右布局；产业、扩散章交换文字与图表位置；证据、实验章使用上方说明与下方通栏图表。各段正文共用固定位置，分别使用纵向分层、横向切换、轻微缩放、淡入、遮罩展开和分段组装，反向滚动时方向反转。旧段约 180ms 淡出，新段约 480ms 进入。快速跳段取消旧过渡；非当前段设置 `inert`，避免透明文字和链接拦截操作。使用原始正文节点，保留步骤锚点；切换到手机、矮窗口或减少动画模式时恢复正文原位置。

通栏模式将说明带与图表放在同一个 `.story-viewport` 固定容器内，避免两种内容高度不同，导致图表退出时标题继续停留并覆盖图表。两个区域共用固定与退出边界；响应式回退和语言替换时拆除容器，恢复原节点位置。

章节背景使用随主题变化的蓝、紫、绿、暖色底与细网格／点阵，覆盖主线和章末探索；结尾也保留背景。所有装饰限于 HW02。桌面每章末尾补足一个舞台高度的滚动空间，最后一张图在完整固定区内完成展开并停留后，舞台才退出。桌面从舞台到达导航下方时才推进首段，图形前 42% 步骤区间展开，剩余区间供阅读；产业网络保持完整连线，切换时只强调当前案例，避免重复重画。

- 不截获滚轮、不自动滚动全页、不强制吸附。
- 叙事阶段与探索参数分开；滚动不会改写用户参数或新增历史记录。
- 正文、来源及数据表由 Astro 静态生成。工作流程图在封面期间准备，其余场景提前至少 1400px 或两个视口高度加载；加载期间显示静态占位。探索图表仍在可见且接近视口时初始化。
- 场景预留最终布局高度，防止逐章加载挤动阅读位置。图形加载失败后移除该预留，回退为普通可读正文。
- 展开内容、切换案例和窗口变化会重新计算章节位置；共用防抖调度，避免各章同时反复刷新。
- 演示需手动启动；离屏、后台或切换语言时暂停。语言切换复用现有 `.story-step` 与 `astro:before-swap / after-swap`，保留步骤位置和查询参数，释放旧观察器与时间线。
- 资料页为 `source-<id>`、`record-<id>` 提供稳定锚点。脚注同时提供原始来源与本站口径入口。

## 手机、减少动画与无脚本

桌面宽度 ≥1024px 且扣除导航后可用高度 ≥560px 时使用左右布局。其他足够高的窗口使用上方紧凑固定图＋下方短文；图高 `clamp(280px,42svh,360px)`。手机可用高度不足 520px，或系统启用减少动态效果时，按步骤顺序展示图与文字。

减少动画时不启用滚动变形或自动演示，实验仍可手动调参。禁用 JavaScript 时所有 21 步、五个案例、完整数据表和默认模型结果保持可读，原生目录链接与详情展开仍可用。静态图解是脚本增强，禁用脚本时以正文、数据和来源提供等价事实内容。

无脚本样式依赖现有 BaseLayout 的 `data-theme` 初始化约定，并限定在 HW02；不在正文 `noscript` 中插入样式，避免语言切换 DOMParser 误激活样式。

## 旧地址兼容

五个旧专题作为静态兼容页保留，含无脚本可点击链接。客户端跳转保留查询参数、语言和部署 base：

- `industries/` → `#applications`，其原收益／扩散／边界锚点分别映射。
- `lab/` → `#parameters`。
- `trends/` → `#adoption`；`work/` → `#benefits`；`transition/` → `#boundaries`。
- 原故事的主要章节／步骤继续使用原 ID；`factory-vision`、`clinical-vision`、`scientific-discovery`、`screening-quality` 映射到对应新产业步骤。

初次深层锚点定位等待场景布局稳定，用户滚轮、触摸、指针或按键立即取消自动校正。语言切换使用公共层已有的步骤位置恢复，不重新强制跳到 URL 锚点。
窗口宽度改变时恢复当前可见步骤，避免手机与桌面布局切换后落到上一段；该恢复同样允许用户输入立即中止。
