## 滚动、动画与加载

CSS sticky 将舞台限制在每章内。所有桌面版式共用一个 `.story-viewport`，正文与图表一起固定和退出。GSAP ScrollTrigger 读取滚动位置，用复用的 `quickTo` tween 在约 0.42 秒内追随；快速跳过超过一屏的距离和深层锚点直接定位到对应状态。D3 负责图形与尺度，向上滚动可还原之前的状态。

版式由图形内容决定：流程／资源依赖使用文字在左的分栏，产业关系／扩散图使用图在左的分栏，研究比较／工时模型使用通栏。通栏说明区按最长实际正文自然撑开，图表占余下空间，不再固定为 220px；`ResizeObserver` 根据正文与可用高度调整每步的阅读距离。所有正文仍只有一份，非当前段设置 `inert`。文字进出距离取自实际区块高度，方向随倒滚反转；打断动画时旧文字从当前可见位置退出，快速跨段直接切换。手机、矮窗口与减少动画模式恢复原正文位置。

动效对应图表含义，集中在用户滚动触发的变化上：

- 工作流程与产业网络保留 SVG 和完整基础连接。AI 支线按滚动接入检索／生产节点，移动圆点说明信息传递；人的复核与交付随后获得强调。产业切段只改变关系强调，节点与连线颜色平滑补间，结束时恢复主题变量。
- 研究结果点从各自基准移动到报告的结果；不同指标使用短暂交叉淡化，不把不同研究或度量拼接成连续数值。
- 采用率按横轴年份展开，点与数值随年份出现；面积图与线使用同一遮罩。
- 企业、投资和暴露的前景条带依次展开，背景轨道和刻度保持完整。能源柱从共同基线升起，历史估计先出现、预测随后出现，虚线区分预测仍保留。
- 工时实验的生产段、复核段与总工时由同一模型连续计算；滚动不更改探索区的四个参数。
- 封面图片随滚动轻微移动，离开封面后停止，不使用自动循环装饰动画。

主线与章末探索共用随明暗主题变化的轻底色；去掉大号装饰数字、英文装饰标签、重复标题及章末网格／点阵／渐变。图表使用安静的独立表面，颜色继续用于图中的语义关系。桌面每章末尾保留一个舞台高度，图形在前 48% 步骤区间完成主要变化，余下空间供阅读，最后一图完整停留后再退出。

- 不截获滚轮、不自动滚动全页、不强制吸附。
- 叙事阶段与探索参数分开；滚动不会改写用户参数或新增历史记录。
- 正文、来源及数据表由 Astro 静态生成。工作流程图在封面期间准备，其余场景提前至少 1400px 或两个视口高度加载；加载期间显示静态占位。探索图表仍在可见且接近视口时初始化。
- 场景预留最终布局高度，防止逐章加载挤动阅读位置。图形加载失败后移除该预留，回退为普通可读正文。
- 展开内容、切换案例和窗口变化会重新计算章节位置；共用防抖调度，避免各章同时反复刷新。
- 演示需手动启动；离屏、后台或切换语言时暂停。语言切换复用现有 `.story-step` 与 `astro:before-swap / after-swap`，保留步骤位置和查询参数，释放旧观察器与时间线。
- 资料页为 `source-<id>`、`record-<id>` 提供稳定锚点。脚注同时提供原始来源与本站口径入口。

## 手机、减少动画与无脚本

桌面宽度 ≥1024px 且扣除导航后可用高度 ≥560px 时使用左右布局。其他足够高的窗口使用上方紧凑固定图＋下方短文；图高 `clamp(280px,42svh,360px)`。手机可用高度不足 520px，或系统启用减少动态效果时，按步骤顺序展示图与文字。

减少动画时不启用滚动变形或自动演示，实验仍可手动调参。禁用 JavaScript 时所有 21 步、五个案例、完整数据表和默认模型结果保持可读，原生目录链接与详情展开仍可用。静态图解是脚本增强，禁用脚本时以正文、数据和来源提供等价事实内容。

无脚本样式依赖现有 BaseLayout 的 `data-theme` 初始化约定，并限定在 HW02；不在正文 `noscript` 中插入样式，避免语言切换 DOMParser 误激活样式。
