网页空间布局要回答三个问题：一个元素占多大空间？多个元素如何排列？容器变窄时，内容如何重新分配空间？下面用六步完成同一个“可视化课程作品浏览页”，而不是学习一组互不相关的小例子。

<div className="prose">

> **案例任务：可视化课程作品浏览页**
>
> 我们要为一门可视化课程制作作品浏览页。学生在页头切换栏目，在侧栏按主题和年份筛选，在主内容区浏览“城市热岛”“通勤流向”“空气质量”等作品，在页脚查看课程说明与数据来源。页面既会独立打开，也会嵌入较窄的课程平台，因此还要能随容器宽度重排。

</div>

六个步骤会依次完成同一页面：先做尺寸可预测的作品卡片，再处理卡片内部的正常流和角标，接着用 Grid 搭页面骨架、用 Flex 排作品工具栏，然后加入容器查询，最后统一验收。前五步各自使用“讲解 / 关键代码 / 展示”标签；第六步把成果连起来检查。

## 第一步：确定作品卡片的盒模型

先从案例中最小的重复单元开始：作品卡片。分清内容、内边距、边框和卡片间距，后续三列作品才不会因为尺寸计算错误而溢出。

### 给第一张作品卡片分配空间

作品卡片从内向外有四层：`content` 放标题和摘要，`padding` 留出内容与卡片边界之间的呼吸空间，`border` 标出可见边界，`margin` 分隔卡片与外部元素。

默认的 `content-box` 会把 `padding` 和 `border` 加到声明宽度之外；`border-box` 会把它们包含在声明宽度里。案例统一设置 `box-sizing: border-box`，让写下的卡片宽度就是页面上看到的宽度。

卡片内部用 `padding`，卡片网格中的统一间距稍后交给 Grid 的 `gap`。作品标题可能很长，所以 Grid 子项还应允许收缩，避免最小内容尺寸撑破页面。

### 本步判断顺序

1. 确定作品卡片的可见宽度，并使用 `border-box`。
2. 用 `padding` 控制卡片内部留白，用 `gap` 控制卡片之间的距离。
3. 为长标题区域设置 `min-width: 0`，保留收缩空间。

### 写出尺寸可预测的作品卡片

```html title="project-card.html"
<article class="project-card">
  <h2>城市热岛地图</h2>
  <p>比较温度与绿地覆盖率。</p>
</article>
```

```css title="project-card.css"
*, *::before, *::after {
  box-sizing: border-box;
}

.project-card {
  width: 320px;
  padding: 20px;
  border: 2px solid #93c5fd;
}
```

作品卡片的可见宽度是 `320px`，内容区会自动扣掉左右 `padding` 和 `border`。如果使用默认的 `content-box`，可见宽度会变成 `364px`（`320 + 40 + 4`），三列排列时更容易超出预期。

## 第二步：让卡片内容保持正常流

有了尺寸可预测的卡片，下一步放入作品标题、摘要和入口。它们应该依次占位并自然撑开卡片；只有“NEW”角标需要叠在右上角。

<HomeworkTabs>
<TabsContent keepMounted value="explanation">
<div className="prose">

### 先让主要内容自然排列

正常流中，块级盒子沿块轴依次排列，行内内容在空间不足时自然换行。案例卡片使用 `position: relative` 建立定位上下文，同时保留卡片原来的占位；角标使用 `position: absolute` 脱离正常流。

标题、摘要和“查看作品”入口不定位，它们继续决定卡片高度。绝对定位适合这种局部叠加，不适合固定整个页头、侧栏或作品区。

摘要变长时，卡片应自动增高。只有确实需要独立滚动的区域才设置明确尺寸和 `overflow: auto`；不要用 `overflow: hidden` 掩盖问题，否则文字和键盘焦点都可能被裁掉。

### 本步定位原则

保留结构内容的正常流，只定位不需要占位的状态信息。定位后还要检查角标是否遮住标题，以及键盘焦点是否可见。

</div>
</TabsContent>

### 只把作品角标移出正常流

```html title="positioned-project-card.html"
<article class="project-card">
  <span class="project-card__badge">NEW</span>
  <h2>城市热岛地图</h2>
  <p>比较温度与绿地覆盖率。</p>
  <a href="#urban-heat">查看作品</a>
</article>
```

```css title="positioned-project-card.css"
.project-card {
  position: relative;
  padding: 24px;
}

.project-card__badge {
  position: absolute;
  inset-block-start: 12px;
  inset-inline-end: 12px;
}
```

父元素仍在正常流中，只有角标脱离正常流。标题、摘要和入口会按顺序占位，并在摘要变长时自然撑高作品卡片。

## 第三步：用 Grid 搭出作品浏览页

卡片内部稳定后，把它放进完整页面。案例需要页头、筛选侧栏、作品主区和页脚，作品区内部还要排列三张卡片，这正是二维 Grid 适合处理的空间关系。

<HomeworkTabs>
<TabsContent keepMounted value="explanation">

### 把案例区域写成轨道

外层 Grid 使用 `160px minmax(0, 1fr)`：筛选侧栏固定为 `160px`，作品区占据剩余空间。`minmax(0, 1fr)` 中的 `0` 允许主列真正收缩，长作品标题不会反过来撑宽页面。

案例区域有清楚的语义，所以使用 `grid-template-areas` 表达 `header`、`sidebar`、`main` 和 `footer`。作品区内部再嵌套一个 Grid，用 `repeat(3, minmax(0, 1fr))` 排列三张卡片。

Grid 只负责空间分配，不替代 HTML 语义。页头、侧栏、主内容和页脚仍使用 `header`、`aside`、`main`、`footer`。

### 分配工具栏的剩余空间

`display: flex` 默认沿水平方向排列子项。`justify-content: space-between` 把标题和类型摘要放在两端，`align-items: center` 保持垂直对齐。

左侧标题区设置 `flex: 1 1 220px` 和 `min-width: 0`，可以占据剩余空间也可以收缩；右侧类型摘要保留自身宽度。工具栏设置 `flex-wrap: wrap` 后，嵌入区域变窄时，类型摘要会换到标题下方，不会被裁切。

这一步也说明 Grid 和 Flex 可以嵌套：Grid 管理作品页的大区域，Flex 管理作品区内部的一行信息。

## 第五步：让作品页适应嵌入容器

宽布局已经完成，但作品页还会嵌入课程平台。容器变窄时，筛选项应移到作品列表上方，三列卡片应改为单列；单纯缩小所有内容不能解决空间关系。

<TabsContent keepMounted value="explanation">

### 让案例根据自身宽度重排

在作品页的嵌入容器上声明 `container-type: inline-size`，再用 `@container` 查询它的内联尺寸。同一个作品浏览页位于完整窗口或课程平台窄栏时，都会根据自己实际得到的宽度变化。

容器查询适合这种可复用区域；`@media` 仍适合整站导航和页面边距等视口级变化。断点应对应具体问题：侧栏是否挤压作品区？三张卡片是否无法舒适并排？

案例把 `560px` 作为重排点。更窄时，外层布局和作品卡片网格都改为单列；作品内容不删减，侧栏宽度设置暂时失效。

### 为作品浏览页声明容器断点

```css title="responsive-project-gallery.css"
.gallery-embed {
  container-type: inline-size;
}

.gallery-layout {
  display: grid;
  grid-template-columns: 160px minmax(0, 1fr);
  gap: 16px;
}

.project-grid {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 16px;
}

@container (max-width: 560px) {
  .gallery-layout,
  .project-grid {
    grid-template-columns: 1fr;
  }
}
```

展示中的“窄容器”会把案例预览限制为 `360px`，低于 `560px` 断点，因此无需改变整个浏览器窗口就能看到重排。

## 第六步：验收完整案例

前五步已经从一张作品卡片推进到完整的响应式作品浏览页。最后把“看起来差不多”改成可以逐项执行的验收条件。

<div className="prose">

### 按案例路径检查

1. **检查作品卡片**：确认 `border-box` 让卡片宽度可预测，内部 `padding` 与卡片间 `gap` 各司其职。
2. **检查卡片内容**：输入更长的作品标题和摘要，确认正文自然撑高卡片，只有角标脱离正常流。
3. **检查页面结构**：确认页头、筛选侧栏、作品区和页脚保留语义元素，Grid 只负责视觉分区。
4. **检查作品工具栏**：切换宽、窄容器，确认标题和类型摘要可以换行，没有内容被裁切。
5. **检查嵌入状态**：切到窄容器，确认筛选项位于作品列表上方、三张卡片改为单列，再用 Tab 键确认焦点可见。

### 集中管理案例中的可调参数

```css title="project-gallery-tokens.css"
.project-gallery {
  --content-max: 72rem;
  --region-gap: 16px;
  --region-padding: 16px;
  --sidebar: 160px;
  width: min(100%, var(--content-max));
  margin-inline: auto;
  padding-inline: var(--region-padding);
  container-type: inline-size;
}

.project-gallery__body {
  display: grid;
  grid-template-columns: var(--sidebar) minmax(0, 1fr);
  gap: var(--region-gap);
}

@container (max-width: 560px) {
  .project-gallery__body {
    grid-template-columns: 1fr;
  }
}
```

这些属性与第五步的实验控件一一对应。出现问题时，可以明确判断是筛选侧栏、区域间距、区域内边距还是容器断点造成的。

### 案例完成标准

- 宽容器中，筛选侧栏固定宽度，作品区占据剩余空间，三张作品卡片并排。
- Grid 负责作品页二维分区，Flex 负责作品工具栏一维排列，`gap` 表达兄弟元素间距。
- 长作品标题和摘要不会撑破卡片，也没有不必要的横向滚动。
- 窄容器中，筛选项与作品列表上下排列，卡片改为单列，全部内容仍然可见、可读、可操作。
